A Python program — standard library only, no network — that writes one line to /output/entry.txt: a fake horoscope for GPT-5.2, whose context window is in retrograde this week and whose favourite conversation will forget it by Thursday. The line sits inside the competition's gate of 1 to 200 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
